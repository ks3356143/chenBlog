## 设计简介

关键点如下

1. 知识点1：`transform: perspective(600px) rotateY(-90deg)`可以使单元素翻转

2. 知识点2：前面翻转隐藏使用正反面概念，该效果使用`opacity: 0 | 1`实现两个元素

            cards.forEach(card => card.classList.add('active'));
            markers.forEach(m => m.classList.add('inactive'));
        });
    });
    cards.forEach(card => {

    });
</script>
