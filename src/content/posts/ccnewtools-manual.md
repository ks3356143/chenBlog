## 一、工具集是干什么的

打开工具后先看到**工具集首页**，里面有两个工具：

![工具集首页](/images/ccnewtools/00-toolset-home.webp)

<div class="horizontal-scroll-container">

| 工具 | 干什么 | 产出 |
|---|---|---|
| **大纲转换** | 导入一份第三方**测试大纲**（.docx），自动解析其中的测试项表格和测试用例，人工核对后一键生成 | 测试说明 + 测试记录 两份 Word 文档 |
| **追踪文档生成** | 导入测试大纲 / 测试记录 / 回归测试说明，生成对应的**需求追踪表** | 大纲 / 说明 / 报告 / 回归说明 四类追踪表 |

</div>

**整个过程不需要联网**，上传的文档和生成的文档都只存在你的电脑上。

**支持平台**：Windows x64（`CCNewTools_v1.4.1_win-x64.exe`）、Linux x64（`CCNewTools_v1.4.1_linux-x64`）、银河麒麟 V10（`CCNewTools_v1.4.1_kylin-v10`）。下文以 Windows 为例，其他平台操作相同。

## 二、快速上手

**工具一（大纲转换）三步走**：

1. 在工具集首页点「大纲转换」卡片 → **拖入测试大纲**（.docx），等解析完成，点「开始核对与编辑」
2. **核对用例**（重点处理标红的“可疑”步骤、填写测试人员与监测人员），点「生成文档」
3. 两份 Word 自动保存到数据目录，完成页显示保存路径（小文档也可直接下载）

**工具二（追踪文档生成）两步走**：

1. 在工具集首页点「追踪文档生成」卡片 → 选追踪表类型 → 按提示拖入文档（部分类型还要配对大纲）
2. 预览追踪表 → 点「复制表格」或「下载」拿走 .docx

下面逐步详解。

## 三、启动工具

双击 `CCNewTools_v1.4.1_win-x64.exe`，会弹出一个**黑色控制台窗口**，随后**默认浏览器自动打开**进入工具界面。控制台窗口内容如下：

```text
测试文档工具集 v1.4.1
服务已启动：http://127.0.0.1:8300
数据目录：…\数据
正在自动打开浏览器（若没有弹出，请手动访问上面的地址）……
关闭此窗口即退出。
```

个别机器没设置默认浏览器时不会自动弹出，请自己打开浏览器（Chrome / Edge / Firefox 均可），在地址栏输入控制台里显示的地址（默认 `http://127.0.0.1:8300`），回车即进入工具集首页。

几个要点：

- **黑色控制台窗口 = 工具本体**，使用期间不要关闭它；关闭它工具就退出了（已做的编辑会自动保存，不会丢）
- 如果 8300 端口被占用，工具会自动换端口（8301、8302……），**以控制台里实际显示的地址为准**
- 顶栏左侧是「‹ 工具集」返回按钮——进入任一工具后随时点它回到首页换另一个工具
- 顶栏中间显示当前工具的操作步骤（大纲转换三步 / 追踪生成两步），可直接点击步骤跳转
- 顶栏右侧的 **?** 图标随时打开一页内置速览说明（丢了手册也能自助）
- 界面右上角的月亮/太阳图标可切换深色主题，选择会记住

## 四、工具一：导入测试大纲

在工具集首页点「大纲转换」卡片进入，第一屏是导入：

![工具一：选择大纲](/images/ccnewtools/01-home.webp)

把大纲 .docx 文件**拖入虚线框**，或**点击虚线框**选择文件。解析需要几秒钟（几百条步骤的大纲约 3~5 秒），期间显示进度条。

**大文档自动分块解析**：大纲正文超过 20MB（约几万条步骤的规模）时，工具自动切换分块解析模式，界面上会提示“预计需要 1~2 分钟”，请耐心等待进度条走完。支持的文件上限：正文 100MB / 压缩包 200MB，带大量截图的大纲都能正常解析（解析只读文档正文文字，图片不参与）。

### 4.1 解析结果

![解析完成](/images/ccnewtools/02-parsed.webp)

解析完成后显示：

- **统计数字**：测试项 / 测试用例 / 测试步骤数量，以及“切分可疑待核对”数量
- **问题清单**：大纲里的告警（如“标题下没有测试项表”、“标识不一致”等），**点击任意一条可跳到对应的用例**去核对
- 点「**开始核对与编辑**」进入第二屏

### 4.2 最近项目（第二次使用起）

![最近项目](/images/ccnewtools/10-recent.webp)

每次成功解析的大纲都会自动保存为一个“项目”，下次使用时**无需重新上传**，点「打开」即可恢复到上次核对的状态（包括你改过的步骤文字）。

- 同一份大纲文件重复上传会自动合并为同一个项目（按内容识别）
- 「删除」需要点两次确认（第二次变为红色“确认删除”），3 秒内不点会自动复原
- 「清空全部」同样是两段式确认

## 五、工具一：核对与编辑

这是使用时间最长的一屏，布局：**左侧大纲树 + 右侧编辑区 + 底部操作栏**。

![核对页全景](/images/ccnewtools/03-review.webp)

### 5.1 全局参数（右侧最上方卡片）

![全局参数](/images/ccnewtools/04-global-params.webp)

对所有用例生效的公共信息，会写进生成的文档：

<div class="horizontal-scroll-container">

| 参数 | 说明 |
|---|---|
| 软件配置项名称 | 用于文档“测试说明”、“需求追踪表”的章节标题，如“XX星指令生成与发控软件配置项” |
| 用例初始化 / 前提和约束 | 已有默认话术，可按需修改 |
| 设计人员 / 测试时间 | 测试时间默认当天 |
| **测试人员 \*、监测人员 \*** | **必填**！不填的话点「生成文档」会被拦截提示 |

</div>

填写内容会自动记住，下次使用不用重填。卡片标题栏可点击折叠/展开。

### 5.2 左侧大纲树

树的层级**与大纲原文完全一致**（配置项 → 测试类型 → 测试组 → 测试项），每个节点旁的数字是该层下的用例数。点击任意用例，右侧立即切换到它。

点击任意父节点（测试类型 / 测试组 / 测试项）可**收缩或展开**该分支，方便聚焦当前核对的子树；搜索时自动全部展开（命中的用例始终直接可见），清空搜索后恢复您的收展状态。

**大文档的树行为**（用例数超过 600 时自动启用）：树默认折叠，逐层点击展开；单个层级下内容过多时只显示前一部分，并提示“还有 N 个未显示，请用搜索定位”——此时用搜索框定位用例最快。

上方的搜索框可以**按用例名称或标识过滤**：

![树搜索过滤](/images/ccnewtools/05-tree-search.webp)

（示例：输入“审查”后，树中只剩相关的 2 个用例，底部显示“匹配 2 / 10 个用例”）

### 5.3 核对用例（右侧主区域）

每个用例显示：所属层级面包屑、用例名称、标识 / 测试需求标识 / 章节、用例综述，以及**测试步骤表**：

- **修改文字**：单击单元格（虚线框）直接编辑，点别处即保存
- **调整步骤**：每行右侧四个按钮——上移、下移、插入一行、删除本行
- **粘贴**：从别处复制文字粘贴进来会自动去掉格式（纯文本）
- 「**不生成此用例**」：把当前用例排除，生成文档时跳过（按钮变为橙色“已排除，点击恢复”，可随时恢复）
- 「**标记已核对**」：确认这个用例没问题，底部核对进度 +1

### 5.4 处理“可疑”步骤（重点）

工具自动切分步骤时拿不准的地方会标红提示，典型原因是“期望结果为空”（大纲原文没写预期）：

![可疑跳转定位](/images/ccnewtools/06-suspicious.webp)

处理方法（二选一）：

1. **确实是问题**：点击红色高亮行里的单元格，补写期望结果——红色标记自动消失
2. **确认无误**：点标签里的「确认无误」链接

底部操作栏的红色「**可疑 n**」胶囊可以**点击循环跳转**，逐个处理所有可疑步骤，全部处理完后胶囊变绿。强烈建议生成文档前把可疑清零。

底部还有：核对进度条（全绿即完成）、「上一条 / 下一条」切换用例、「全部已核对」一键完成、黄色「告警 n」胶囊点开可查看解析告警清单。

## 六、工具一：生成与下载

核对完成后，点底部右侧的「**生成文档**」按钮（前提：测试人员、监测人员已填），自动进入生成页：

![生成中](/images/ccnewtools/07-generating.webp)

生成过程按测试项表格逐张渲染，日志实时滚动。完成后自动跳到结果页：

![生成完成](/images/ccnewtools/08-generated.webp)

- **两份文档自动保存到数据目录**：`数据\生成\<项目>\测试说明-生成.docx` 和 `测试记录-生成.docx`，完成页会显示每个文件的名称、大小和**完整保存路径**，直接到该目录取用即可（每次生成自动覆盖同目录旧文件）
- **小文档额外保留「下载」按钮**（10MB 以内），文件同时在浏览器默认的“下载”文件夹里——两种方式拿到的是同一份文件
- 如果解析时有告警，页面顶部会出现**黄色警示横幅**——文档仍已生成，但建议点「返回修改」核对告警涉及的内容后再出正式文档
- **测试记录超过 2000 个用例时自动跳过记录文档**（记录表体量太大超出了 Word 能打开的范围，这是 Word 的硬限制），完成页会显示蓝色提示条说明原因——请按测试类型把大纲拆成多个分册分别导入生成；**测试说明不受此限制**
- 「**查看生成日志**」可展开完整日志（每个测试项一行，⚠ 为告警）：

![生成日志](/images/ccnewtools/09-log.webp)

生成完成后可「返回修改」重新生成，或「重新开始」处理下一份大纲。

## 七、工具二：追踪文档生成

在工具集首页点「追踪文档生成」卡片进入。工具按要贴入的目标文档分四类，**先选类型再导入**：

![追踪工具：四类追踪表选择](/images/ccnewtools/12-trace-home.webp)

<div class="horizontal-scroll-container">

| 类型 | 上传什么 | 生成什么表 |
|------|---------|-----------|
| 大纲追踪 | 测试大纲 | 大纲附件2「测试项与软件需求规格说明对照表」（7 列；大纲里写了研制任务书追踪时自动加任务书两列变 9 列） |
| 说明追踪 | 测试大纲 **或测试说明**（自动识别） | 测试说明「需求的可追踪性」追踪表（8 列） |
| 报告追踪 | 测试记录 ＋ 大纲或说明 | 报告附件2「软件满足软件需求规格说明对照表」（11 列） |
| 回归说明 | 回归测试说明 ＋ 测试大纲 | 回归说明「需求的可追踪性」需求追溯表（9 列） |

</div>

### 7.1 操作流程（以报告追踪为例）

1. 点「报告追踪」页签
2. **配对大纲**：报告追踪需要一份大纲（或测试说明）作对照——可以从最近项目里选，也可以现场上传一份：
   ![报告追踪：配对大纲或说明（自动识别）](/images/ccnewtools/13-trace-report-pair.webp)
3. **拖入测试记录**（.docx），等解析完成
4. 进入预览页核对追踪表——同一测试项的多个用例**纵向合并**显示：
   ![报告追踪表预览：执行结果列可编辑、备注自动填问题单](/images/ccnewtools/15-trace-report-preview.webp)
5. 点「复制表格」直接去 Word 里粘贴，或点「下载」拿 .docx 文件

说明追踪表的预览（8 列，从测试大纲或测试说明直接生成）：

![说明追踪表预览：双层表头、同测试项纵向合并](/images/ccnewtools/14-trace-note-preview.webp)

### 7.2 使用要点

- 大纲追踪表按大纲实际内容自动定形态：全部测试项都没写研制任务书追踪 → 任务书块整块省略（7 列）；任一测试项写了 → 自动加任务书块（9 列）；章节号列一律在章节名称列前面
- 报告追踪的执行结果列默认「通过」（全步骤通过且无问题单时），可在预览表里逐条改完再复制/下载；备注列自动填记录里的问题单号
- 同一测试项的多个用例在表格里纵向合并显示，复制进 Word 保留合并单元格
- 说明文档作源时，需求规格说明两列会留空（说明文档里没有该数据），贴入后请人工补齐
- 用例标识与配对文档对不上的行会点名告警并留空，不影响其余行生成
- 预览最多显示 200 行，复制与下载不受限；下载的 .docx 样式与对应文档中的追踪表一致
- 每类追踪的源文档也会存成项目（按类型分类显示在“最近项目”里），下次直接打开不用重传

## 八、数据保存在哪里（重要）

所有数据都在 **exe 所在目录的 `数据/` 文件夹**里：

```text
CCNewTools_v1.4.1_win-x64.exe
数据/
├── 项目/       每份源文档一个项目目录（大纲/记录/回归说明源文件副本 + 你的全部编辑）
├── 生成/       工具一生成的文档（每次生成按项目归档，自动覆盖旧文件）
├── 设置.json   全局参数、主题
└── 日志/       运行日志（自动滚动保留最近 5 个）
```

- **编辑随时自动保存**——关浏览器、关控制台窗口都不会丢，下次「打开」项目继续
- **换电脑 / 换目录**：把 **exe 和 `数据/` 文件夹一起拷贝**过去即可，什么都不用重新做
- **升级新版本**：用新 exe 覆盖旧的，`数据/` 不用动
- 启动时控制台窗口会显示数据目录的实际位置；万一 exe 旁边不可写（比如放在只读目录），会改存到 `C:\Users\<用户名>\CCNewTools\` 并在控制台提示

## 九、常见问题

**Q1：双击 exe 后只弹了个黑窗口，界面没出来？**

通常浏览器会自动弹出。个别机器没设置默认浏览器时不会弹，请在浏览器地址栏手动输入黑窗口里显示的地址（默认 `http://127.0.0.1:8300`）。建议收藏该地址或设为浏览器主页。

**Q2：提示“端口被占用”或地址不是 8300？**

工具会自动顺延端口（8301、8302……），以控制台窗口显示的实际地址为准。

**Q3：上传时报“这是旧版 .doc 格式”／“文档已加密”／“不是有效的 .docx”？**

- 旧版 .doc：用 Word 打开后「另存为」→ 格式选 `.docx` 再导入
- 加密文档：先解密再另存为 .docx
- 其他提示（文件为空 / 超过 100MB / 非 Word 文件）：确认选的是正确的大纲原文件（带截图的大纲几百 MB 以内都能正常解析，解析只读文档正文，图片不参与）

**Q4：大纲还在 Word 里开着，能直接导入吗？**

可以，工具以只读方式读取，不影响 Word。但注意：**Word 里未保存的修改读不到**，建议先在 Word 里保存再导入。

**Q5：杀毒软件报毒／拦截？**

单文件 exe 无数字签名，部分杀软会误报。添加信任/白名单即可；建议先在一台机器试用确认。

**Q6：我改的步骤文字会不会丢？**

不会。编辑自动保存到 `数据/项目/`，中途关闭浏览器、重启电脑都不丢，重新「打开」项目即恢复。

**Q7：生成的文档在哪儿，能改成别的名字吗？**

文档自动保存在 `数据\生成\<项目>\` 目录（完成页会显示完整路径），文件名固定为“测试说明-生成.docx”和“测试记录-生成.docx”，在文件管理器里重命名或复制出来归档即可（建议按“配置项名 + 日期”）。文档**内容**里的标题、章节、人员信息都以你在工具里填写的为准。

**Q8：解析出来的用例数量和大纲对不上？**

看第一屏的问题清单（黄色告警），常见原因是大纲里某个标题下没写测试项表、或表格格式特殊。点告警条目可跳到对应位置核对。

**Q9：想换深色界面？**

右上角月亮/太阳图标切换，自动记住：

![深色主题](/images/ccnewtools/11-dark.webp)

**Q10：浏览器打开后页面一片空白？**

浏览器版本太旧（需要 2022 年以后的 Chrome / Edge / Firefox）。内网机器浏览器被统一管理时很常见，换新版 Edge 或 Chrome 再试。

**Q11：公司代理环境下打不开页面？**

浏览器的代理设置需要「绕过本地地址」：在代理例外/白名单里加上 `127.0.0.1`，或勾选“对于本地地址不使用代理服务器”。

**Q12：下载的 exe 首次运行被蓝色提示拦下？**

Windows 对无数字签名程序的常规提示（SmartScreen）：点「更多信息」→「仍要运行」即可。

**Q13：同事把 exe 放在压缩包里直接双击运行，行吗？**

能运行，但 Windows 会把它解到临时目录里，数据也会跟着存在临时目录，电脑清理后就“全部消失”了。请先把 exe 解压到普通文件夹（如 `D:\测评工具\`）再运行；工具检测到这种情况会在启动的黑窗口里提示。

**Q14：追踪表复制到 Word 里，合并单元格没了？**

请用预览页的「复制表格」按钮（而不是截屏或手动誊抄）——它复制的是带合并信息的表格，粘贴进 Word 会保留纵向合并单元格。个别旧版 WPS 对合并支持不完整，出现散行时手动合并一下即可。

**Q15：说明追踪 / 报告追踪里“需求规格说明”两列是空的？**

这是正常现象：以测试说明作源（或说明+记录配对）时，说明文档里没有需求规格说明章节号和条目名这两项数据，工具留空并提示人工补齐——贴入目标文档后按你们的需求规格说明书补上即可。
