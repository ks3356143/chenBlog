## 设计简介

设计一个大水滴，然后内部8个元素旋转展示“摔的感觉”，外部6个元素旋转，旋转出去和回来使用transform-origin实现

- 核心知识1：融合效果也称之为Gooey Effect效果，核心是filter属性的两个函数配合，缺一不可

    关键组合是：`filter: contrast()` + `filter: blur()`，分别作用在不同层级

    | 属性                      | 作用层级 |                                            作用                                            |
    | :------------------------ | -------: | :----------------------------------------------------------------------------------------: |
    | `filter: contrast(20-30)` |   父容器 | 提高整体对比度，强制将子元素边缘模糊收缩回来，<br>边缘被吸收的感觉，从而呈现融合的液态感觉 |
    | `filter: blur(2px-10px)`  |   子元素 |                          让元素边缘模糊，产生向外扩散的“粘性边缘”                          |

## 实现代码和步骤

### HTML部分

容器`.frame`设计超大对比度`filter:contrast(25)`

一个中心圆当做`filter: blur(15)`大一点吸收边缘模糊，8个小球扩展中心圆，起到弹性效果

另外6个球改变`transform-origin`，在外部rotate摔出然后回来融合

```html
<div class="frame">
    <div class="center">
        <div class="ball"></div>
        <div class="blubb-1"></div>
        <div class="blubb-2"></div>
        <div class="blubb-3"></div>
        <div class="blubb-4"></div>
```

### CSS部分

首先外部大容器作为大对比度容器

```css
.frame {
    width: 400px;
    height: 400px;
    box-shadow: 1px 2px 10px 0 rgba(0, 0, 0, 0.3);
    background-color: #000;
    border-radius: 2px;
    filter: contrast(25);
}

.center {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}
```

然后中心园，边缘模糊强烈一点`filter: blur(15px)`

```css
.ball {
    position: relative;
    width: 90px;
    height: 90px;
    background-color: #fff;
    border-radius: 50%;
    filter: blur(15px);
}
```

内部八个小球，边缘较小模糊`filter: blur(5px);`，`transform-origin`不超过大圆球，导致圆球边缘有突出感觉
