# 关于我 / About Me

你好，我是 **KisJuyial**（朋友们叫我**老陈**）——一个写界面、也写代码的人。

2026 年这一年，我大半的活落在 **UI/UX** 上：测试管理工具的树形工作台、Windows 上的单人 AI 工作站、命令行工具的官网落地页、编辑器主题的皮肤改造。我在意的不是「能不能跑」，而是「一眼能不能看懂、点下去有没有回应」。

## 🎨 现在在做什么

- **界面设计与前端实现**：把设计系统真正落到界面里——令牌、直角骨架、动效分层，而不是停在设计稿上
- **工程化的自用工具**：测试管理工具 **ChenMeridian**、测试文档工具集 **CCNewTools**，以及一批自用小工具
- **把判断存下来**：每个项目里想明白的设计决定，收进一个本地知识库，下次直接取用，不再从零想一遍

## 📚 我的个人知识库

做界面真正的麻烦不是难，是**同一个判断要反复重新想**——卡片要不要圆角、主按钮该不该上渐变、深色底上灰字怎么分层。所以我给自己搭了一个知识库：Obsidian 编辑、git 管版本，按设计系统的标准分成 **基础 / 组件 / 模式 / 页面 / 案例** 五档；每个领域只留一个取用入口，拿着「我要做什么」直接对号，一次只读一篇。

到现在二十来篇正文，绝大多数是 UI/UX 设计，两条取用路径：按任务找、按颗粒度拼装。细节写在
[《老陈的个人知识库：UI/UX 设计经验怎么变成能查的东西》](/posts/chen-knowledge-base/)。
